**Did:** Verified all five M0 VS Code extensions were installed and actually
firing, not just listed. Set global git user.name and user.email. Installed
Claude Code. Generated an ed25519 SSH key, added the public half to GitHub,
and cloned the learning-log repo over SSH.

**Broke:** `claude doctor` returned "command not found" twice. First time I
was in a Git Bash terminal inside VS Code, not PowerShell — the installer is
a PowerShell command, so it had never run. Second time it had installed
correctly to `C:\Users\absol\.local\bin\claude.exe` but that folder wasn't on
my PATH, so the shell couldn't find the bin.    

**Learned:**
- "Installed" and "on PATH" are two different things. When a command isn't
  found, check whether the file exists before reinstalling anything.
- A PATH change only reaches processes started *after* it. VS Code needs a
  full restart, not a new terminal tab.
- Used `[Environment]::SetEnvironmentVariable` rather than `setx`, because
  `setx` truncates PATH at 1024 characters and can silently destroy it.
- SSH auth works on a key pair: the private key never leaves this machine,
  GitHub only ever sees the `.pub` half.
